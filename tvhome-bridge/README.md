# Experimental HOME bridge

This tiny source-only APK forwards a HOME launch to Projectivy. It was tested as
a privileged product application, but the customized firmware still rejected it
as a HOME candidate. It is retained because that negative result narrows future
research; it is **not** part of the final working configuration.

The reliable solution on the investigated build was Projectivy installed as an
ordinary application with its accessibility service enabled.
